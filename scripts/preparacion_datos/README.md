# Preparación de datos

Esta carpeta contendrá scripts auxiliares para preparar, validar y organizar los datos antes de aplicar las métricas.

Posibles tareas futuras:

- validar archivos listados en metadata.csv,
- normalizar nombres de archivos,
- revisar duración de audios,
- convertir formatos,
- verificar sample rate,
- preparar subconjuntos por hablante, grupo o sistema TTS.
