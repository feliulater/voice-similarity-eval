# Enlaces externos de datos

Esta carpeta documenta enlaces a recursos externos donde se almacenan archivos que no deben subirse directamente a GitHub, como audios, modelos pesados o resultados grandes.

La idea es que GitHub contenga el código, la documentación, los metadatos y las configuraciones, mientras que los archivos pesados se mantienen en un almacenamiento externo como OneDrive.

Se recomienda documentar cada recurso externo en `links_template.csv`.
