# Organización de resultados

Los resultados deben guardarse por corrida experimental para evitar sobrescribir archivos y facilitar la comparación entre experimentos.

Estructura sugerida:

results/runs/YYYYMMDD_nombre_experimento/
  identidad/
  frecuencia/
  calidad/
  perceptual/
  resumen/

Los archivos pesados o generados automáticamente no deberían subirse directamente a GitHub, salvo resúmenes ligeros en CSV, Markdown o figuras seleccionadas.
