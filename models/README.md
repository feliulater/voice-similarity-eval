# Organización de modelos

Esta carpeta documenta los modelos utilizados para evaluación y generación.

No se recomienda subir pesos pesados directamente a GitHub. En su lugar, se deben documentar:

- nombre del modelo,
- fuente,
- versión,
- propósito,
- procedimiento de instalación,
- observaciones de compatibilidad.

Los pesos o archivos grandes deben mantenerse en almacenamiento externo y enlazarse desde `data/external_links/`.
