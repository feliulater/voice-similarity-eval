# Configuraciones de experimentos

Esta carpeta contendrá archivos de configuración para definir experimentos sin modificar directamente los scripts.

Ejemplos futuros:

- experimento_base.yaml
- comparacion_xtts_elevenlabs.yaml
- voces_infantiles.yaml

La idea es que cada archivo de configuración indique qué metadatos usar, qué grupo de voces evaluar, qué sistemas TTS comparar, qué métricas ejecutar y dónde guardar los resultados.
